## Why functools-kit?

functools-kit consolidates the async and functional patterns you'd otherwise wire together from multiple packages. Every utility is designed to compose cleanly with the others.

<CardGroup cols={2}>
  <Card title="Async HOFs" icon="gears">
    Rich wrappers for concurrent, sequential, and fault-tolerant async operations — including cancellation, pooling, queuing, and retries.
  </Card>
  <Card title="Reactive Streams" icon="signal">
    Full observer/subject pattern with `map`, `filter`, `debounce`, `merge`, `join` operators — build reactive pipelines without extra dependencies.
  </Card>
  <Card title="Smart Caching" icon="memory">
    Cache results by key, by argument fingerprint, or with time-to-live expiry. Per-key state routing prevents memory leaks.
  </Card>
  <Card title="Data Iteration" icon="layer-group">
    Async generator-based document iteration with offset/cursor pagination, filtering, mapping, and union merging.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Install the package">
    ```bash
    npm install functools-kit
    ```
  </Step>
  <Step title="Import what you need">
    ```typescript
    import { cancelable, Subject, ttl, iterateDocuments } from "functools-kit";
    ```
  </Step>
  <Step title="Use it in your code">
    ```typescript
    import { debounce, ttl } from "functools-kit";

    // Debounce expensive operations
    const onSearch = debounce((query: string) => fetchResults(query), 300);

    // Cache with automatic expiry
    const getUser = ttl(
      async (userId: string) => fetchUser(userId),
      { key: ([id]) => id, timeout: 60_000 }
    );
    ```
  </Step>
  <Step title="Explore the API reference">
    Browse the [API Reference](/api/cancelable) for full type signatures and parameter docs for every export.
  </Step>
</Steps>
