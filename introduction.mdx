functools-kit is a zero-runtime-dependency TypeScript library that consolidates the async orchestration, reactive programming, and functional utility patterns you would otherwise assemble from several separate packages. It ships with a clean, type-safe API and is verified by 761 tests covering both functional correctness and async exception propagation.

## What functools-kit does

The library is organized into six broad areas, each designed to compose cleanly with the others.

## Key exports by category

### Async HOFs

| Export | Description |
|---|---|
| `cancelable` | Wraps a promise-returning function with cancellation support; returns `CANCELED_PROMISE_SYMBOL` when cancelled |
| `queued` | Serializes async calls into a promise queue |
| `execpool` | Limits concurrent executions to a configurable pool size |
| `retry` | Retries on failure with configurable attempt count and delay |
| `lock` | Functional mutex — serializes access to shared async resources |
| `singlerun` | Runs only once until explicitly cleared with `.clear()` |
| `afterinit` | Skips the first invocation; runs all subsequent calls normally |
| `timeout` | Resolves to `TIMEOUT_SYMBOL` if the wrapped call takes too long |
| `schedule` | Defers execution using a caller-supplied scheduler callback |
| `obsolete` | Marks a function as deprecated with a runtime warning |

### Caching

| Export | Description |
|---|---|
| `memoize` | Cache by a key function; supports `clear()` |
| `cached` | Cache invalidated by argument change detection |
| `ttl` | Time-to-live cache with optional garbage collection |
| `router` | Per-key cached memoization — routes each key to its own cached result |
| `rate` | Rate limiting by key with `RateError` on breach |

### Reactive

| Export | Description |
|---|---|
| `Observer` | Full observable implementation with operator chaining |
| `Subject` | Observable + subscriber — push values with `.next()` |
| `BehaviorSubject` | Subject that replays its current value to new subscribers |
| `Source` | Factory for observers: `fromArray`, `fromPromise`, `fromInterval`, `merge`, `join`, `pipe` |
| `Operator` | Stream operators: `take`, `skip`, `distinct`, `group`, `pair`, `count`, `strideTricks`, `retry` |
| `waitForNext` | Await a subject value that satisfies a predicate |

### Data structures

| Export | Description |
|---|---|
| `Lock` | Class-based mutex with `acquireLock` / `releaseLock`; throws on extra release |
| `SortedArray` | Array sorted by numeric score with `push`, `pop`, `take` |
| `LimitedSet` | `Set` capped at a configurable max size with LRU eviction |
| `LimitedMap` | `Map` capped at a configurable max size with LRU eviction |
| `ToolRegistry` | Type-safe runtime registry with `register` / `get` |

## Test coverage

functools-kit ships with **761 tests** across three categories:

- **Spec tests** — functional correctness for every module, including `Observer`, `Subject`, `BehaviorSubject`, `Source`, `Operator`, all async HOFs, caching utilities, data structures, string/array helpers, and document iteration APIs.
- **E2E tests** — async exception propagation through every operator and source type, including multi-hop chains, scoped unhandled-rejection guards, and integration pipelines modelling ETL, IoT, and event-sourcing patterns.
- **Integration tests** — 40 Subject-based and Source-based pipelines verifying throw propagation at every operator position, repeated with `process.on("unhandledRejection")` guards to confirm no exceptions leak.
